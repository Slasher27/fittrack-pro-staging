# FitTrack Pro

Coaching platform for South African personal trainers and their clients, and a standalone tracker.
SvelteKit + Tailwind + Supabase. Offline-first member app, online trainer workspace.

Start here: [CLAUDE.md](CLAUDE.md) (how to work in this repo) and [docs/PROGRESS.md](docs/PROGRESS.md) (where things stand).
The full specification is in [docs/](docs/README.md).
